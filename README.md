# What Makes a Song Popular?

Data science project analyzing Spotify audio features to identify patterns
in popular music. Course project for CSC 108 / MATH 080, Spring 2026.

## Data
Exported from Spotify using Exportify. Initial analysis uses the
"ALL TIME BANGERS – BEST SONGS IN HISTORY" playlist (426 tracks).

## Methods
- Exploratory data analysis (pairplot, correlation heatmap, boxplots)
- Simple linear regression: Energy vs. Loudness

## Files
- `Initial_Project_Presentation_108.ipynb` — main analysis notebook
- `BEST_SONGS_IN_HISTORY.csv` — Spotify export
